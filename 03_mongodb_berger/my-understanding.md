<query>

Syntax: { <field>: <value>, ... }

db.movies.find({ genre: "Drama", year: { $gte: 2000 } })


## $gt Greater Than (>) =  year: { $gt: 2000 } หาข้อมูลที่มากกว่า 2000

## $gte	Greater Than Equal (>=) year: { $gte: 2000 } หาข้อมูลที่มากกว่าหรือเท่ากับ 2000

##  $lt	 Less Than (<)  year: { $ls: 2000 } หาข้อมูลที่น้อยกว่า 2000

##  $lte Less Than (<=)  year: { $ls: 2000 } หาข้อมูลที่น้อยกว่าหรือเท่ากับ 2000

## แถม: ตัวย่อที่ใช้บ่อยใน Code (เช่น MongoDB)
เวลาเราเขียน Query เรามักจะไม่พิมพ์เครื่องหมาย < หรือ > ตรงๆ แต่จะใช้ตัวย่อแทนครับ:
ตัวย่อ	คำเต็ม	แปลว่า	สัญลักษณ์
$lt	Less Than	น้อยกว่า	<
$lte	Less Than Equal	น้อยกว่าหรือเท่ากับ	<=
$gt	Greater Than	มากกว่า	>
$gte	Greater Than Equal	มากกว่าหรือเท่ากับ	>=

## <projection>parameter

## <projection>parameter  เปรียบเสมือนการเลือกคอลัมน์ใน SQL ช่วยให้เราดึงมาเฉพาะข้อมูลที่จำเป็น 

## ใช้สำหรับระบุว่าฟิลด์ (field) ไหนบ้างที่ควรจะรวมเข้าไว้ หรือตัดออกไปจากเอกสาร (document) ที่ส่งกลับมา ซึ่งมันช่วยให้คุณควบคุมหน้าตาหรือโครงสร้างของเอกสารในชุดผลลัพธ์ได้"

1 (หรือ true): เพื่อ "รวม" ฟิลด์นั้นในผลลัพธ์ 

(เลือกเฉพาะข้อมูลที่ตรงเงื่อนไข)
0 (หรือ false): เพื่อ "ยกเว้น" หรือซ่อนฟิลด์นั้น  (เลือกเฉพาะส่วนประกอบภายในข้อมูลนั้นๆ)
